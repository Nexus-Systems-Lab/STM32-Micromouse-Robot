## Project Overview

This project was developed as part of our participation in the **MicroMaze 3.0 Robotics Competition at IIT**.

The objective was to design and develop an autonomous Micromouse robot capable of navigating a maze using an STM32 microcontroller, sensor feedback, and motor control techniques.

## Implemented Features

- **Hardware Design and Integration:** Assembled and integrated the STM32-based robotic platform with motors and hardware components.
- **Embedded Firmware Development:** Developed firmware using C to control and coordinate robot operations.
- **Motor and Motion Control:** Implemented motor control functionality for forward motion, turning, and directional adjustments.
- **Robotic System Integration:** Integrated hardware and software components to establish a functional robotic prototype.
- **System Testing:** Conducted practical testing and validation of implemented movement functionality.

## Technologies Used

- **Microcontroller:** STM32
- **Programming Language:** C
- **Sensors:** Time-of-Flight (ToF) Sensors
- **Motors:** Encoder-Based DC Motors
- **Communication:** I²C
- **Development Area:** Embedded Systems, Robotics, Motor Control, Sensor Interfacing

## Current Project Status

**Status: Ongoing Development**

The hardware integration and initial motion-control implementation have been completed. Further development focuses on autonomous navigation, maze mapping, and path-planning functionality.
